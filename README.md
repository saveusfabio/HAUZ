# Studio / 001 — V1

Website e guideline para um estúdio de design voltado a painting contractors nos EUA.

## Arquivos
- `AGENTS.md`: instruções permanentes do projeto; exige consultar e manter o guideline atualizado quando decisões de design ou experiência mudarem.
- `dist/index.html`: página completa em inglês.
- `dist/styles.css`: sistema visual e adaptações responsivas.
- `dist/app.js`: revelações, cursor, labels, comparação, menu, formulário de demonstração e privacidade.
- `dist/assets/`: fotografias locais.
- `docs/DESIGN-GUIDELINE.md`: análise da referência e especificação de design/motion.

O guideline é a fonte de continuidade para as decisões visuais e de experiência. Quando uma mudança estabelecer uma nova regra reutilizável, documente a decisão e o motivo nele junto com a implementação.

## Rodar
Com Node instalado, executar `npm start` nesta pasta. Abrir http://127.0.0.1:4173.
Não há instalação de dependências nem etapa de build. `npm run check` verifica a sintaxe do JavaScript.

## Status
Identidade provisória, conceito de portfólio identificado como demonstração, formulário que somente exibe uma prévia e não envia dados. Não há backend, analytics ou serviço de email conectado. Lenis 1.3.27 e sua licença MIT estão incluídos localmente; Geist e Fragment Mono ainda são carregados pelo Google Fonts. Acesso da publicação inicial privado.

## Próximas decisões
Naming, logo, fundador, oferta/preço, hospedagem/suporte e destino de formulários. Ver `docs/DESIGN-GUIDELINE.md` para manter continuidade.
